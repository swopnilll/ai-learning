# AWS GenAI Developer tutorial (Next.js)

Animated, icon-driven study tutorial. Next.js app; the lesson engine is plain JS in `public/`.

- `npm install && npm run dev` to run locally
- Add a lesson: create `public/lessons/NN-name.js`, then list it in `lessons.ts`
- Icons: `public/assets/` (AWS icon set + logos). Short names are in `public/js/helpers.js`
- Deploy: push to GitHub, import the repo in Vercel (no config needed)
